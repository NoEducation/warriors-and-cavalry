# backend-server

The multiplayer web server for Warriors and Cavalry, written in .NET. Not scaffolded yet — see
`AGENTS.md` for the planned layout and conventions, and `../docs/superpowers/specs/` for the
design documents.

```
backend-server/
├── src/      server projects (*.csproj)
├── tests/    test projects (<Project>.Tests)
└── Directory.Build.props   shared build settings for every project
```
