# Combat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Spearmen and Archers trained at a Barracks fight raider waves that march on the Keep and break buildings.

**Architecture:** A new `Army` in `src/sim/` owns every `Unit` (both sides), the Barracks training queues and the
raid schedule; `Structures` keeps building hit points. Both follow objects through `ObjectLifecycle`. Commands go
through `World.apply`; `World.tick` ticks the army last. Render reads `UnitView`s; game code owns the selection and
sends commands.

**Tech Stack:** TypeScript (strict), three.js, Vitest, Vite.

**Spec:** `docs/superpowers/specs/2026-11-27-combat-design.md`

## Global Constraints

- `src/sim/` imports nothing outside it, no `three`/DOM/`Date`/`performance`/`crypto`; `Math` only `floor`, `sqrt`,
  `abs`, `min`, `max`, `imul` (`tests/simPurity.test.ts`).
- Changes only through `World.apply` / `World.tick`; per-tick loops in ascending id order; integer ticks and hit points.
- One class per file, named after it; explicit member modifiers and return types; doc comment on every public method;
  no `enum`; files under ~150 lines; config in one frozen object per area.
- CSS colours only as variables in `src/ui/colors.css`.
- No new dependencies. No AI attribution in commits or PRs.
- Iterate with `npx vitest run <files>`; the gate is `npm test` and `npm run build` on the committed HEAD.

## Review Focus

- A unit whose target, march building or breach building disappears mid-walk (demolished, killed by someone else)
  must re-plan, never strike a stale id or throw. Test in Task 5.
- "New map" while raiders are alive: nothing from the old army may leak into the new world's layers or selection.
  Test in Task 9 (layer dispose) and Task 10 (selection reset).
- Orders listing the same unit twice, raider ids or dead ids must not crash or move raiders. Test in Task 4.
- A raider whose march target is unreachable even with breaching (water) must wait and retry, not search every
  tick. Test in Task 6.
- Demolishing a Barracks with a queue while soldiers stand: room drops, soldiers stay, queue gone. Test in Task 3.
